Description: This is my app "Campsite Commander". The application serves as inventory app for outdoor adventures. The app stores camping gear and food supplies, allowing users to categorise them and provides a detailed checklist to the user.

Features: Clean UI, large buttons improve usability on mobile devices, readable fonts to enhance accessibility, consistent colour scheme creating a cohesive experiance.

Technologies used: Kotlin, Android Studio, XML, GitHub.

Installation: Clone the repository, open in Android Studio, Run the app.

GitHub Usage: GitHub was used for version control, allowing tracking of changes and maintaining a history of development.
